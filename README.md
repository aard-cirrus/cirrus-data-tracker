# Cirrus Data Tracker (CDT)

A [MUSHclient](https://mushclient.com/) plugin for [Aardwolf](https://www.aardwolf.com/) that records what you
earn, deal, take and heal, as it happens, into a local SQLite database, and turns it into reports, rates,
projections and live meter windows.

**The first public release is on its way.** When it is out it will appear under
[Releases](../../releases) with the plugin file, and this page will have the full documentation.

## Requirements

- MUSHclient 4.73 or later.
- The Aardwolf MUSHclient package, with GMCP on.
